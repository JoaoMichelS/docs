# Contatos do Parceiro

A aba **Contatos** dentro de cada contrato em vigência mantém o cadastro das pessoas-chave da contraparte. Ter contatos atualizados é essencial para comunicações de rotina, renovações, cobranças e resolução de incidentes.

## Como cadastrar um contato

1. Abra o contrato.
2. Vá para a aba **Contatos**.
3. Clique em **Novo Contato**.
4. Preencha:

| Campo | Obrigatório | Descrição |
|-------|-------------|-----------|
| **Nome** | Sim | Nome completo |
| **Cargo** | Recomendado | Função no parceiro |
| **Email** | Sim | Email principal |
| **Telefone** | Recomendado | Telefone com DDD |
| **Tipo de contato** | Sim | Comercial, financeiro, jurídico, técnico, gestor |
| **Observações** | Não | Anotações livres |

5. Salve.

## Tipos de contato

Categorizar o contato por tipo facilita identificar a quem recorrer em cada situação:

| Tipo | Quando usar |
|------|-------------|
| **Comercial** | Negociações, propostas, ampliações |
| **Financeiro** | Faturas, pagamentos, cobranças |
| **Jurídico** | Aditivos, alterações contratuais, disputas |
| **Técnico** | Operação do dia a dia, suporte, integração |
| **Gestor** | Ponto focal estratégico |

<Tip>
  Você pode cadastrar **mais de um contato do mesmo tipo**. Indicado para parceiros grandes com áreas separadas.
</Tip>

## Visualização

Dentro da aba, os contatos aparecem em uma tabela:

| Coluna | Conteúdo |
|--------|----------|
| Nome | Nome completo |
| Cargo | Função |
| Tipo | Categoria |
| Email | Email principal (com link `mailto:`) |
| Telefone | Telefone com link de chamada |

Clique em uma linha para editar ou visualizar o detalhe completo.

## Edição e exclusão

- **Editar** — qualquer campo pode ser alterado a qualquer momento.
- **Excluir** — remove o contato do contrato. Requer confirmação.

<Warning>
  Excluir um contato é permanente. Se houver chance de reutilização, prefira marcá-lo com observação "inativo" em vez de excluir.
</Warning>

## Reaproveitamento entre contratos

Cada contrato tem sua **própria lista de contatos**, mesmo quando vários contratos são com o mesmo parceiro. Isso é intencional: o contato responsável por um contrato pode não ser o mesmo de outro.

Se quiser, você pode duplicar manualmente os contatos ao criar um novo contrato com o mesmo parceiro.
